## 🚀 Proyectos destacados

### 🏘️ Plataforma inmobiliaria a medida

Aplicación web para un corredor de propiedades, orientada a que el **administrador gestione de forma centralizada** ventas, arriendos y terrenos.

| | |
|---|---|
| **Problema** | El corredor necesita gestionar su cartera sin depender de plataformas genéricas ni intermediar comunicaciones entre terceros. |
| **Decisión de diseño** | Modelo de **gestión centralizada**: no existe conexión directa entre compradores y propietarios; todo el contacto pasa por el corredor. |
